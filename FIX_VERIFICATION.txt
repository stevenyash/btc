Key Changes:
------------
1. Added Migration Queue System (lines 43-78)
   - MAX_CONCURRENT_MIGRATIONS = 2 (configurable)
   - pendingQueue array for storing queued jobs
   - activeMigrations counter for tracking current jobs
   - processMigrationQueue() function for managing queue

2. Modified POST /migrate/:lessonId endpoint (lines 121-174)
   - Jobs now queued instead of immediate execution
   - Duplicate detection (checks active + queued jobs)
   - Returns "queued" status to client

3. Modified POST /migrate-batch endpoint (lines 230-317)
   - All jobs queued first
   - Processed 2 at a time (configurable)
   - Clear response with queued count

4. Added Duplicate Prevention (lines 40-47, 284-289)
   - Prevents same lesson from being migrated multiple times
   - Checks both active jobs and pending queue

Queue Processing Flow:
----------------------
1. Migration request received
2. Validate and check duplicates
3. Add to pendingQueue with "pending" status
4. Call processMigrationQueue()
5. If active < MAX_CONCURRENT, start migration
6. On completion, decrement counter
7. After 1s delay, process next in queue
8. Failed jobs don't block queue
