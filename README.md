## Payments and customer support

The admin transaction screen shows payment amounts, M-Pesa references, phone numbers, and whether a recorded payment completed its lesson-access activation. Client support requests are submitted from the Contact page; customers can retain the private tracking code to check status and read staff replies. Admins manage requests at `/admin/support`.

Before deploying the support API, apply `nodejs-express-api/migrations/20261030_support_tickets.sql` to the configured MySQL database.
